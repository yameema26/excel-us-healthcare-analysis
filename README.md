# US Healthcare Data Analysis

## Project Overview

This project explores US healthcare data using Microsoft Excel.
It focuses on data cleaning, patient and billing analysis, hospital
admission trends, and the use of spreadsheet tools to organise
and visualise healthcare information.

The project uses Excel features to examine the dataset and present
information through tables, charts, and an interactive dashboard.

## Objectives

- Clean and validate healthcare data.
- Analyse patient demographics and medical conditions.
- Examine hospital stays, billing amounts, and insurance providers.
- Explore admission trends and hospital resource-management factors.
- Present the analysis using PivotCharts and an interactive dashboard.

## Tools and Technologies

- Microsoft Excel
- Power Query
- Excel Functions
- PivotTables
- PivotCharts
- Slicers
- Conditional Formatting

## Key Analysis Areas

### 1. Data Cleaning and Validation
Handled missing values, checked duplicates, corrected data types,
and used Power Query for data transformation.

### 2. Patient and Billing Analysis
Analysed patient demographics, medical conditions, hospital stays,
billing amounts, and insurance providers using Excel functions
and PivotTables.

### 3. Admission and Resource Analysis
Examined admission trends and factors related to hospital
resource management.

### 4. Data Visualisation and Dashboard
Created PivotCharts and an interactive dashboard using slicers
and conditional formatting.
