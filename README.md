# US Healthcare Case Study — Excel

## Project Overview

This project explores healthcare data using Microsoft Excel. It demonstrates the use of spreadsheet tools to organise, examine, and analyse data in a healthcare-related case study.

## Project Objectives

* Explore and organise healthcare data.
* Apply Excel tools to examine the dataset.
* Practise data analysis and interpretation.
* Present information in a structured and understandable format.

## Tools and Technologies

* **Microsoft Excel**
* **Data Analysis**
* **GitHub**

## Project File

* The Excel workbook in this repository contains the US Healthcare case study.

## Key Skills

* Spreadsheet-based data analysis
* Data organisation
* Analytical thinking
* Working with Excel datasets

Download the Excel workbook from this repository and open it using Microsoft Excel or a compatible spreadsheet application.
